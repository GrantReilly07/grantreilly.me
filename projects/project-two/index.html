The project

A museum, sorted
by color.

Met Color connects a simple RGB value to an artwork in the Met's collection. I built a Java program to calculate average colors from artwork images, then an Azure Functions backend to find the nearest match.

The image data comes from a Met Open Access dataset on Hugging Face. The generator uses a selected list of artworks in two-dimensional mediums and saves each image's average red, green, and blue values to a CSV.

Think of the average as the whole image reduced to a single swatch. It includes every pixel, including backgrounds and borders, so a colorful painting can still average to a quiet, neutral tone.

Behind the match

From pixels to paintings.

  1. 01

    Calculate once

    The Java generator downloads each image, adds up every pixel's RGB channels, and divides by the number of pixels. The result is one saved average color per artwork.

  2. 02

    Find the nearest color

    The backend loads those colors into memory and compares them to your selection. It returns the artwork with the smallest squared RGB distance.

    d² = (R − r)² + (G − g)² + (B − b)²
  3. 03

    Meet the artwork

    This page uses the matching object ID to request the Met's collection record, then displays the original image and catalog details.

RGB distance measures numerical closeness, so the closest average won't always look like the closest color to your eyes. The demo searches the project's saved selection, rather than every artwork in the museum.
